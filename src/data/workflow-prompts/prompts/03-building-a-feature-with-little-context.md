03 — BUILDING A FEATURE WITH LITTLE CONTEXT

I want to add [describe the feature] to this codebase. Do not write any code yet.

First investigate:

1) which existing files and modules this feature will most likely touch,
2) whether a similar feature already exists that I should copy the pattern from, and exactly where it lives,
3) the naming conventions, error handling, and testing patterns used elsewhere so my code matches them,
4) existing utilities, hooks, or services I should reuse instead of writing from scratch,
5) edge cases this codebase seems to care about, based on how similar features validate input and handle errors.

Then output a numbered implementation plan with file paths and a one line description of the change needed in each file.

Stop and wait for my approval before writing any code.
