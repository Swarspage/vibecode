55 — TECHNICAL SEO, PERFORMANCE & WEB PLATFORM AUDIT

Act as a senior technical SEO and web performance specialist. Audit this
project's public web presence. If it is not a website, adapt the audit to
the closest deliverable: web app, landing page, docs site, or API docs.

Audit these areas:

1) Metadata
   - title tags
   - meta descriptions
   - canonical URLs
   - Open Graph and Twitter cards
   - favicon and theme color

2) Crawlability
   - robots.txt
   - sitemap.xml
   - internal linking
   - correct use of noindex/nofollow
   - URL structure and redirects

3) Semantic HTML
   - heading hierarchy
   - landmarks
   - image alt text
   - links vs buttons
   - form labels

4) Structured Data
   - JSON-LD presence
   - schema types used
   - whether the structured data is valid

5) Core Web Vitals
   - LCP, INP, CLS
   - render-blocking resources
   - image optimization
   - font loading strategy
   - JavaScript bundle size

6) Performance
   - unused CSS/JS
   - code splitting
   - caching headers
   - compression
   - CDN usage

7) Mobile Experience
   - viewport meta
   - responsive behavior
   - tap target sizes
   - mobile usability

8) Security Headers
   - CSP
   - HSTS
   - X-Content-Type-Options
   - Referrer-Policy
   - Permissions-Policy

9) Accessibility overlaps
   - contrast
   - focus visibility
   - reduced-motion support
   - skip links

For every issue, provide:

- severity: critical / high / medium / low,
- the file or route affected,
- a clear explanation of the problem,
- a specific fix or next step.

End with:

- the top ten highest-impact improvements,
- any automated tools or CI checks you would add,
- a prioritized action plan.

Do not change code. Provide the audit as a report only.
