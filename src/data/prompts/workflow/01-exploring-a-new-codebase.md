01 — EXPLORING A NEW CODEBASE

Act as a senior engineer doing a first pass on this repository. Read the README, package manifest, and entry point files first. Then produce:

1) a summary of what this application does and who it is for,
2) the tech stack with exact versions pulled from the manifest files,
3) an annotated folder tree covering only directories that matter, skip node_modules, build output, and vendor folders, with one line per folder explaining its role,
4) the five to eight files you would read first if you had one hour, ranked by importance, with a reason for each,
5) the exact commands to install dependencies, run the project locally, and run the test suite, taken directly from config files, not guessed.

If something is unclear from the code, say so instead of assuming.
